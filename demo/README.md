# Demo documents

Fictional legal documents for the live demo. Copy the `documents` folder to the demo computer and open the files while Screenpipe records. TimeKeepr recognizes each case from what appears on screen.

All names, companies, cases, and facts are invented. Placeholders in brackets, such as `[ADDRESS]` or `CASE [NUMBER]`, stand for details a real document would contain.

| Folder | Case reference | What it shows in the demo |
| --- | --- | --- |
| `2025-031 Dupont v Martin` | `2025-031-DUPONT` | Recognition from the case reference in file names and the email subject, and from the opposing party `Martin Distribution` in the text. |
| `2026-009 Commercial lease - Dupont` | `2026-009-DUPONT` | A second case for the same client: the client name alone does not decide the case. |
| `2026-012 Articles of association - SAS Lumen` | `2026-012-LUMEN` | Flat-fee case. |
| `2026-015 Shareholders agreement - SAS Lumen` | `2026-015-LUMEN` | Hourly case for the same company. |
| `2026-004 Divorce - Bernard` | `2026-004-BERNARD` | Family law case with a court petition and hearing notes. |
| `Unsorted` | none | No reference and no known marker: TimeKeepr cannot recognize the case and asks the lawyer. |

File types match a lawyer's daily work: drafts in Word (`.docx`), documents received or signed in PDF, and emails (`.eml`, open them in any mail client).
