# Demo documents

Fictional legal documents for a future live demo. Copy the `documents` folder to the demo computer and open the files while Screenpipe records. The current application uses prepared fictional recognition signals; live Screenpipe ingestion is not connected yet.

All names, companies, cases, and facts are invented. Placeholders in brackets, such as `[ADDRESS]` or `CASE [NUMBER]`, stand for details a real document would contain.

| Folder | Case reference | What it shows in the demo |
| --- | --- | --- |
| `2025-031 Dawson v Martin` | `2025-031-DAWSON` | Recognition from the case reference in file names and the email subject, and from the opposing party `Martin Distribution LLC` in the text. |
| `2026-009 Commercial lease - Dawson` | `2026-009-DAWSON` | A second case for the same client: the client name alone does not decide the case. |
| `2026-012 Bylaws - Lumen Inc` | `2026-012-LUMEN` | Flat-fee case. |
| `2026-015 Shareholders agreement - Lumen Inc` | `2026-015-LUMEN` | Hourly case for the same company. |
| `2026-004 Divorce - Bennett` | `2026-004-BENNETT` | Family law case with a court petition and hearing notes. |
| `Unsorted` | none | No reference and no known marker: TimeKeeper cannot recognize the case and asks the lawyer. |

File types match a lawyer's daily work: drafts in Word (`.docx`), documents received or signed in PDF, and emails (`.eml`, open them in any mail client).
